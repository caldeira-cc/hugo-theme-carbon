The **W3C CSV on the Web (CSVW)** engine provides declarative tabular dataset exploration. Datasets are loaded alongside `.csv-metadata.json` descriptors that specify column types, titles, and validation constraints.

## Available Live Datasets

- [**Global Edge Server Telemetry**](/data/server-telemetry/): Real-time cluster health, CPU/RAM utilization, and regional availability statuses.
- [**High-Frequency Financial Benchmarks**](/data/financial-benchmarks/): Deterministic transaction latency benchmarks and SLA pass/fail verification.
