## 1. Carbon AI Label (`ai-label`)

The `ai-label` shortcode implements the official **IBM Carbon Design System v11 AILabel component** (`cds--ai-label`). It provides a standardized mechanism to disclose AI-synthesized or assisted text.

When clicked, the badge opens an explainability popover dialog detailing why and how the content was produced.

### Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `text` | String | *Optional* | Explanation text inside the popover |
| `heading` | String | `"AI-generated content"` | Title inside the popover dialog |
| `size` | String | `"sm"` | Size variant (`xs`, `sm`, `md`, `lg`) |
| `inline` | Boolean | `false` | When `true`, displays as a compact inline token |

### Standalone Example

{{< ai-label text="This summary text was generated by an AI model to illustrate how technical writers can provide full explainability for machine-assisted drafts." />}}

```markdown
{{</* ai-label text="This summary text was generated by an AI model to illustrate how technical writers can provide full explainability for machine-assisted drafts." /*/>}}
```

### Paired Shortcode Example

{{< ai-label heading="AI Content Notice" >}}
This section contains synthetic data generated using a large language model to test table pagination and sorting behaviors without relying on private datasets.
{{< /ai-label >}}

```markdown
{{</* ai-label heading="AI Content Notice" */>}}
This section contains synthetic data generated using a large language model to test table pagination and sorting behaviors without relying on private datasets.
{{</* /ai-label */>}}
```

## 2. Callouts & Editorial Asides (`callout`)

The `callout` shortcode highlights crucial context, warnings, tips, and AI disclosures.

### Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `type` | String | `"info"` | Callout type (`info`, `success`, `warning`, `error`, `ai`) |
| `title` | String | *Optional* | Header title for the callout |
| `closeable` | Boolean | `false` | When `true`, implements the official Carbon React `ActionableNotification` with an accessible close button |
| `actionText` | String | *Optional* | Label for action button (converts to `ActionableNotification`) |
| `actionHref` | String | *Optional* | Target link URL for the action button |
| `lowContrast` | Boolean | `false` | When `true`, displays lower contrast container styling |
| `hide_icon` | Boolean | `false` | When `true`, hides the leading status icon |

### Examples

{{< callout type="info" title="System Requirement" >}}
Hugo Extended edition v0.149.0 or higher is required to compile Dart Sass and process ESBuild modules.
{{< /callout >}}

{{< callout type="success" title="Zero External CDNs" >}}
All fonts, scripts, and vector assets are bundled directly from origin, ensuring privacy and compliance with strict data regulations.
{{< /callout >}}

{{< callout type="warning" title="Submodule Update Notice" closeable="true" >}}
Remember to initialize submodules with `git submodule update --init --recursive` when cloning for the first time. This notification is dismissible via the close button.
{{< /callout >}}

{{< callout type="info" title="Interactive Quickstart" actionText="Getting Started" actionHref="/docs/" >}}
Explore comprehensive instructions for configuring sites, layouts, and data engines.
{{< /callout >}}

{{< callout type="ai" title="AI-Assisted Section" >}}
This callout uses the `type="ai"` modifier, rendering Carbon's purple accent border and AI icon to signal synthesized documentation prose.
{{< /callout >}}

```markdown
{{</* callout type="info" title="System Requirement" */>}}
Hugo Extended edition v0.149.0 or higher is required to compile Dart Sass and process ESBuild modules.
{{</* /callout */>}}

{{</* callout type="warning" title="Submodule Update Notice" closeable="true" */>}}
Dismissible callout rendered using Carbon React ActionableNotification pattern.
{{</* /callout */>}}

{{</* callout type="info" title="Interactive Quickstart" actionText="Getting Started" actionHref="/docs/" */>}}
Explore comprehensive instructions for configuring sites, layouts, and data engines.
{{</* /callout */>}}

{{</* callout type="ai" title="AI-Assisted Section" */>}}
This callout uses the `type="ai"` modifier, rendering Carbon's purple accent border and AI icon to signal synthesized documentation prose.
{{</* /callout */>}}
```

## 3. Code Snippets & File Viewers (`code-snippet`, `code-file`)

### Code Snippet (`code-snippet`)

Renders a terminal or code block with one-click clipboard copying.

{{< code-snippet type="multi" >}}
# Install Hugo Extended on macOS via Homebrew
brew install hugo

# Clone and run local preview
git clone https://github.com/caldeira-cc/hugo-theme-carbon.git
cd hugo-theme-carbon/exampleSite
hugo server -p 1316
{{< /code-snippet >}}

```markdown
{{</* code-snippet type="multi" */>}}
# Install Hugo Extended on macOS via Homebrew
brew install hugo
{{</* /code-snippet */>}}
```

### Code File Viewer (`code-file`)

Renders a labeled file viewer displaying file path, line count, and a copy button:

{{< code-file path="config/_default/hugo.yaml" lang="yaml" lines="true" >}}
baseURL: "https://example.org/"
title: "Production Portal"
theme: "hugo-theme-carbon"
params:
  carbon:
    useLocalFonts: true
    defaultThemeMode: "system"
{{< /code-file >}}

```markdown
{{</* code-file path="config/_default/hugo.yaml" lang="yaml" lines="true" */>}}
baseURL: "https://example.org/"
title: "Production Portal"
{{</* /code-file */>}}
```

## 4. Status Tags (`tag`)

Tags categorize content and convey status. They map directly to Carbon tag color tokens.

### Examples

<div style="display: flex; gap: 0.5rem; flex-wrap: wrap; margin: 1rem 0;">
  {{< tag type="blue" text="Core Engine" >}}
  {{< tag type="green" text="Passing Tests" >}}
  {{< tag type="purple" text="Carbon v11" >}}
  {{< tag type="red" text="Deprecated" >}}
  {{< tag type="warm-gray" text="Draft" >}}
  {{< tag type="outline" text="RFC 7946" >}}
</div>

```markdown
{{</* tag type="blue" text="Core Engine" */>}}
{{</* tag type="green" text="Passing Tests" */>}}
{{</* tag type="purple" text="Carbon v11" */>}}
```

## 6. Mathematical Typesetting (`math`)

The `math` shortcode renders mathematical equations via KaTeX using self-hosted IBM Plex Math OpenType fonts without runtime network latency:

{{< math >}}
f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi)\,e^{2 \pi i \xi x} \,d\xi
{{< /math >}}

```markdown
{{</* math */>}}
f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi)\,e^{2 \pi i \xi x} \,d\xi
{{</* /math */>}}
```
