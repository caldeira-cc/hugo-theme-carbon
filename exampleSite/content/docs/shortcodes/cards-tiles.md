## 1. Card (`card`)

The `card` shortcode implements the expressive Carbon card component. Cards support optional eyebrows, status tags, action links with arrow icons, media headers, and the official **Carbon AI modifier** gradient border.

### Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | String | *Optional* | Card headline |
| `eyebrow` | String | *Optional* | Pre-heading taxonomy or category label |
| `href` | String | *Optional* | Target link URL |
| `actionText` | String | `"Learn more"` | Label for the footer action button |
| `tag` | String | *Optional* | Status tag text displayed in the header |
| `tagColor` | String | `"blue"` | Tag colorway (`blue`, `green`, `red`, `purple`, `warm-gray`) |
| `icon` | String | `"arrow--right"` | Icon name for the action link |
| `ai` | Boolean | `false` | When `true`, applies the Carbon AI gradient border and AI badge |
| `aiText` | String | *Optional* | Explainability description for the AI popover |

Learn how the theme compiles SCSS via Dart Sass and bundles vanilla JavaScript modules at build time with zero external CDNs.

## 2. Base Tile (`tile`)

The base `tile` shortcode renders a clean rectangular container using `--cds-layer-01` background and standard border tokens. It can be formatted as a static block or a selectable item.

### Example

{{< tile >}}
**Static Carbon Tile**: A structural container used to present grouped information with standard Carbon layer padding and subtle boundary borders.
{{< /tile >}}

```markdown
{{</* tile */>}}
**Static Carbon Tile**: A structural container used to present grouped information with standard Carbon layer padding and subtle boundary borders.
{{</* /tile */>}}
```

### Tile with AI Modifier

{{< tile ai="true" aiText="This tile specimen contains AI-synthesised demo text." >}}
**AI-Flagged Container**: Tiles configured with `ai="true"` render an accessible AI slug badge in the top right corner and a distinctive multi-colour gradient border.
{{< /tile >}}

## 3. Clickable Tile (`clickable-tile`)

The `clickable-tile` turns the entire surface into a focusable link with keyboard accessibility and active state elevation.

### Parameters

| :--- | :--- | :--- | :--- |

| `title` | String | *Optional* | Tile headline |

## 4. Expandable Tile (`expandable-tile`)

The `expandable-tile` divides content into two sections: an above-the-fold summary always visible, and an expanded drawer revealed when the user clicks the interactive chevron. Use the `<!-- more -->` separator in Markdown to designate the split.

### Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | String | Required | Header title for the tile |

### Example

{{< expandable-tile title="Click chevron to view full configuration details" >}}
**Visible Summary**: Essential deployment parameters are defined in `hugo.yaml`.
<!-- more -->
**Expanded Detail**: Additional settings—such as Web Worker batch sizes, MapLibre GL initial coordinates, and local font paths—can be configured under `params.carbon` or overridden per section via front-matter cascade.
{{< /expandable-tile >}}

```markdown
{{</* expandable-tile title="Click chevron to view full configuration details" */>}}

{{</* /expandable-tile */>}}
```

## 5. Digital Business Cards (`vcard`)

The `vcard` shortcode parses RFC 6350 vCard files (`.vcf`) or direct parameters to render an interactive contact card complete with:
- Instant `.vcf` file download.
- One-click contact copying to clipboard.
- Pure client-side, zero-network QR code generation.

### Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `file` | String | *Optional* | Path to a `.vcf` file in `static/` |
| `name` | String | *Optional* | Contact full name |
| `title` | String | *Optional* | Professional job title |
| `org` | String | *Optional* | Organisation or department |
| `email` | String | *Optional* | Email address |
| `phone` | String | *Optional* | Phone number |
| `website` | String | *Optional* | Personal or organisation website |
| `location` | String | *Optional* | City and country |
| `badge` | String | *Optional* | Role badge label |
| `badgeColor` | String | `"blue"` | Tag colorway |
| `github` | String | *Optional* | GitHub profile URL |
| `linkedin` | String | *Optional* | LinkedIn profile URL |

### Example

{{< vcard
    name="Open Source Maintainer"
    title="Hugo Theme Engineering"
    org="Hugo Carbon Project"
    email="maintainer@example.org"
    phone="+44 20 7946 0990"
    website="https://carbon.caldeira.cc"
    location="London, United Kingdom"
    badge="Public Domain"
    badgeColor="green"
    github="https://github.com/caldeira-cc/hugo-theme-carbon" >}}
Reference contact card specimen demonstrating dynamic VCF generation, clipboard synchronization, and offline QR rendering.
{{< /vcard >}}
